A full-stack e-commerce application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).
A full-stack e-commerce application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). ShopKart provides a complete online shopping experience with secure authentication, product management, shopping cart, order processing, reviews & ratings, and an admin dashboard.

## 🚀 Live Demo

Frontend: https://shopkart-mern-ecommerce.vercel.app

Backend API: https://shopkart-mern-ecommerce.onrender.com

---

## 📌 Features

### 👤 Authentication

* User Registration
* User Login
* JWT Authentication
* Protected Routes
* Role-Based Access Control (Admin/User)

### 🛍 Shopping Features

* Browse Products
* Search Products
* Product Details Page
* Add to Cart
* Update Cart Quantity
* Checkout Process
* Order Management
* Order History

### ⭐ Reviews & Ratings

* Submit Product Reviews
* Star Ratings (1–5)
* Average Product Rating
* Review Count

### 👨‍💼 Admin Features

* Admin Dashboard
* Manage Products
* Add/Edit/Delete Products
* Manage Users
* Manage Orders
* Product Image Uploads

### ☁️ Cloud Features

* Cloudinary Image Upload
* MongoDB Atlas Database
* Render Backend Deployment
* Vercel Frontend Deployment

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/aakib-0101/shopkart-mern-ecommerce.git
cd shopkart-mern-ecommerce
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```
